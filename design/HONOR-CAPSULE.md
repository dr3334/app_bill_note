# 荣耀灵动胶囊接入与界面边界

核实日期：2026-10-17。目标设备：用户自述荣耀 100 Pro / MagicOS 10，尚未取得系统完整构建号或完成真机测试。本次仅研究公开官方资料，未申请权限、未联系平台、未调用服务。

**设计决策：主流程完成应用内识别、确认、入账与动效；系统灵动胶囊保留为可申请的增强能力。公开文档证实第三方接入渠道存在，但尚不能确认记账/OCR 属于开放场景。原型中的系统胶囊须标明“概念预览，接入待确认”，不能展示成已经接通。**

## 1. 名称与能力不要混用

| 名称 | 官方证据与本项目含义 |
| --- | --- |
| 灵动胶囊 | 荣耀官方称谓；位于状态栏区域，可展开为动态通知，系统决定出现时机、持续时间和交互。不是应用可任意绘制的通用顶部容器。[荣耀全局意图白皮书](https://developer.honor.com/cn/docs/white_paper/guides/introduction) |
| YOYO 建议 / 全局触达 | 第三方服务触达用户的接入路径；可涉及胶囊、AOD、锁屏通知、桌面卡片。需要配置服务场景并审核。[全局触达配置指南](https://developer.honor.com/cn/doc/guides/101455) |
| 动态通知 | 官方设计文档中胶囊展开后的通知形态，不应与任意一条普通 Android 通知画等号。[全局触达设计指南](https://developer.honor.com/cn/doc/guides/101538) |
| 荣耀任意门 | 用户圈选/拖拽内容后向服务跳转的入口；开发者用 deeplink 或 Activity 接收文本、图片等内容。适合作为“把截图交给记账”的候选入口，不是付款监听或胶囊通知 API。[任意门开发指南](https://developer.honor.com/cn/doc/guides/101465) |
| 实况窗 / 灵动岛 | 本次未在荣耀接入文档中核实为上述能力的正式接口名称；本项目需求、设置项统一写“荣耀灵动胶囊”，不借其他品牌名称推断兼容性。 |

## 2. 有真实第三方接口，但不是任意通知即胶囊

**端侧渠道。** 全局触达官方流程是集成 Suggestions Kit、按约定场景格式同步数据、双方联调卡片；云侧方案则通过设备 UUID 与伙伴云同步订单等数据。[全局触达业务介绍](https://developer.honor.com/cn/doc/guides/101452)

SDK 公布的依赖为 `com.hihonor.mcs:intelligence-suggestion`。本次检索到版本页最高条目为 `1.0.0.308`（2025-04-09）；`1.0.0.306` 曾新增 `feedbackOrder`。这是已查到的公开版本，不保证控制台没有更新包。[SDK 版本信息](https://developer.honor.com/cn/kitdoc/MagicLive/11003/guides/version-history.md)

**事件渠道。** 官方端侧示例包含 `Suggestion`、`FeedbackClient`、`feedbackEvent` 和 `hasFeature(FEEDBACK_EVENT)`；必须设置 App ID，反馈需使用对应业务意图编码，处理未授权、限流、参数错误等。云侧公开 POST 事件端点为 `https://intelligentservice-drcn.cloud.honor.com/api/events-notify/v1`，服务端使用应用级 AccessToken。该 API 的存在不代表所有事件都会进入胶囊，仍依赖场景、配置及批准范围。[事件通知开发流程](https://developer.honor.com/cn/doc/guides/101439)

**实现前需要消除文档歧义。** 同一事件开发页示例注释将结束状态写为 `01`，参数表却写为 `11`。当前仅设计，不把任何一个值写进实现契约；联调时必须以对应场景协议和实际返回为准。不要把泛称“状态提醒”的编码直接当作记账胶囊批准。

## 3. 开放场景与记账适用性

公开全局触达场景清单包含外卖、到店取餐、商超、买药、社区团购、排号、抢票提醒、票务履约、券核销，以及航班、高铁、打车、导航、车控。**尚未找到普通记账成功、单张截图 OCR、批量账单导入的明确开放条目。** 没列出不等于永久拒绝，但不能承诺可接入。[全局触达业务介绍](https://developer.honor.com/cn/doc/guides/101452)

以下为产品建议，并非平台批准结果：

| 记账状态 | 当前界面安排 | 系统胶囊定位 |
| --- | --- | --- |
| 自动识别到单笔消费、短时解析 | 应用内顶部轻提示/识别指示；随后账目进入清单 | 暂不依赖胶囊；短时任务可能来不及形成有价值的系统进度 |
| 单笔“已记账” | 列表插入动效与短提示，提供“查看/撤销” | 仅可做演示候选；不得据系统支付成功演示推断第三方获准 |
| 重复账单 | 清单内合并结果与“查看原记录” | 无需系统胶囊 |
| 金额/分类待确认 | 待确认列表、数量标记；后台可使用用户允许的普通通知 | 不能长时间占用胶囊催确认 |
| 用户主动开始、确有持续时间的批量导入/OCR | 可取消的应用内进度、已处理数量、失败项与结果页 | 优先提交评估的候选；有开始/进度/结束语义，但公开场景清单未确认 |
| 权限失效、识别中断 | 明确故障说明与恢复入口；保留已处理内容 | 应用内提示，必要时普通通知；不包装成已有胶囊能力 |
| 预算/日报/月报 | 统计页或用户订阅的汇总通知 | 不建议冒充持续任务常驻胶囊 |

胶囊只是结果/进度的展示渠道，不能解决微信支付宝的数据获取权限，也不能证明识别、入账或付款结果真实。支付成功必须来自可靠交易证据；界面不得用“已支付”代替“已记账”。

## 4. 申请、测试及适配门槛

Suggestions Kit 的权限页面明确：个人和企业开发者均可申请该服务，但应用数据反馈属于受限开放能力，需要审核；应用须注册并配置 SHA-256 签名指纹。[权限申请](https://developer.honor.com/doc/guides/101594) **这只说明 SDK 能力申请资格，不等于应用市场的发布主体资格。**

全局触达还要独立配置场景、出卡频次、分发素材和落地页；提交含胶囊等入口的高保真交互稿，接入审核通过后进入测试；测试名单是手机白名单，需要效果录屏和测试报告，再申请场景上线。[配置与上线指南](https://developer.honor.com/cn/doc/guides/101455)

开始正式开发前待确认的具体问题：

1. “记账识别结果”或“用户主动批量导入进度”是否接受，归属哪一场景/意图编码；是否只允许特定合作伙伴。
2. 该场景采用 `feedbackEvent`、`feedbackOrder` 或专属格式；结束/取消/失败状态、刷新频率、有效期和限流值。
3. 最低 MagicOS、YOYO/系统服务、SDK 版本及中国区荣耀 100 Pro 支持范围；SDK `hasFeature` 只代表接口能力，不能替代场景准入和显示验收。
4. 测试包与正式签名、灰度策略、系统设置开关、用户关闭后行为；所有展示入口的数据与隐私要求。

这些是后续对接清单，本次未替用户发邮件或提交申请。

## 5. 荣耀 100 Pro / MagicOS 10 的证据边界

荣耀官方参数：屏幕 6.78 英寸、2700 × 1224 像素；机身 163.7 × 74.7 mm。产品介绍为四曲屏、最高 120 Hz。屏幕物理像素不是 Android 布局 dp，不能按 1224 宽硬编码界面。[官方参数](https://www.honor.com/cn/phones/honor-100-pro/spec/)、[官方产品介绍](https://www.honor.com/cn/phones/honor-100-pro/)

官方产品维护账号在 2026-04-03 发布的媒体胶囊说明包含荣耀 100 系列，提到 MagicOS `10.0.0.135` 的媒体音频律动。这能证明该系列有系统胶囊功能记录，**不能证明记账场景开放，也不是通用胶囊 SDK 的最低版本声明。**[官方媒体胶囊说明](https://club.honor.com/cn/thread-30132372-1-1.html)

本次未从可读取的官方规格正文取得 100 Pro 前摄开孔的精确位置、尺寸及该构建版本胶囊占位坐标；产品图链接未能成功显示，故不作“中央固定胶囊”精确复刻承诺。原型暂用非硬件精确的系统通知概念。最终使用真机 `WindowInsets` / 显示开孔安全区域与实际系统渲染验收，应用内容避让状态栏和底部手势区。

官方设计规范明确胶囊存在黑色、彩色形态，并按机型自动适配；建议短状态文案 3–4 字，图标与服务匹配。动态通知还需要避让挖孔。我们可以准备“识别中”“已记账”“待确认”等候选文案、应用图标和跳转目标，但胶囊外框、位置、展开动画由系统方案决定，不能保证与应用内墨色清单、底部 Dock 使用完全相同的动效。[设计指南](https://developer.honor.com/cn/doc/guides/101538)

## 6. 降级与原型表达

- 应用内始终完整呈现进度、结果、失败和待确认任务，系统胶囊不是唯一入口。
- 无审批、接口不支持、调用失败、服务开关关闭或系统未展示时，退回应用内反馈；确需后台进度时另行使用符合 Android 生命周期及通知权限的普通通知，不将其称为荣耀胶囊。
- 系统胶囊预览与实际应用内提示分开标识；不以悬浮窗伪装系统胶囊，不增加读屏/悬浮权限只为复制外观。
- 用户选择隐藏金额时，候选系统入口只显示“已记账/待确认”和计数，金额及商家进入应用后查看；系统展示失败不重放入账动作，避免重复账目。
- 真机验收至少覆盖：系统完整版本、字体/显示大小、浅深色、手势/三键导航、前后台切换、锁屏、用户关闭服务、取消/失败/结束、连续多笔、重复事件、低电量与断网。通过服务回调不等于已经屏幕可见，需录屏核验。
