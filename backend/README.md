# 可选后端接口合同

这里仅有 [OpenAPI 3.0.3 草案](openapi.yaml)，**没有服务程序、部署、域名、密钥或已开通的接口**。当前 Android 示例账本完全在本地运行，不依赖后端，也没有向该合同发送请求的网络客户端。

唯一拟定功能是：用户主动预览并同意上传文本后，得到仍需本地确认的识别候选。它不读取微信/支付宝账户，不提供全量个人支付流水，不在云端直接创建或修改账单。图片上传、账号注册、云同步、支付订单接口均不属于本合同。

## 未来实现必须满足的边界

- 默认关闭，逐次主动触发。收到规则结果不等于允许上传；本地识别失败也不能自动切换云端。
- 身份凭据属于未来服务账号，绝不要求支付密码、微信/支付宝 cookie、私有接口 token 或第三方 App 数据目录。
- 只接受最小化文本，先让用户看到发送内容；不顺带发送设备标识、完整截图或其他账单。
- Idempotency-Key 按账号隔离，相同 key 不同请求体返回 409。幂等记录只保存必要摘要/结果，具体保留期限、删除能力和可见隐私说明在实现前确定；本草案不宣称已提供任何数据保留保证。
- 返回未知字段为空和待确认状态，不编造金额/商户/交易时间。金额使用十进制字符串传输、CNY 分整数语义；边界两端精确验证 `1..99_999_999_999` 分（单笔最高 999,999,999.99 元），与本地 `Money.MAX_AMOUNT_MINOR` 一致，不能经过 Double。
- 接入任何模型提供商前明确处理地点、发送字段、费用、失败重试及保留政策；不得将提供商密钥放入 App 或日志。
- 超时、限流、断网、关闭云端功能都不影响本地账本；取消网络请求不得触发“已入账”提示。

实现后应做鉴权、跨账号访问、幂等冲突、超限请求、撤销同意、错误脱敏及数据删除测试，并重新验证合同。当前只能验收 YAML 结构和接口设计，不能据此宣称后端已完成。
