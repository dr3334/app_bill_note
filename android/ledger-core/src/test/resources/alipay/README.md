# 支付宝真实页面的人工转录

三份 UTF-8 文本对应用户提供的支付成功、转账成功、账单详情截图。原图仅本地保留，不随源码分发。

这些是按视觉阅读顺序人工转录的解析测试输入，**没有运行 OCR，也不是设备采集结果**。商户、收款方昵称、亲情卡持有人和收款方全称已换成示例文字；头像没有复制。金额、优惠、广告干扰数字保留，用于验证字段含义与优先级。账单日期、支付时刻和账单状态栏时刻为合成值，保留测试需要的时间关系；状态栏时间不作为交易时间。

`AlipayRealPageTranscriptTest` 还从这些输入构造币种/负号/日期拆行、无主金额、优惠和广告金额、收入与转账等反例。图片到文本的实际效果由用户在真机验证。
