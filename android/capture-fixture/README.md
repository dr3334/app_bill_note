# 仅限模拟器的采集合成夹具

此模块不是支付宝，不处理真实支付。它仅在本项目的测试模拟器上，以相同包名生成合成通知、可读节点和无文字节点的 Canvas 页面，用于验证系统服务到本地账本的完整连通性。它不能证明真实支付宝的文案、页面结构、安全策略或荣耀后台行为。

**不要分发，也不要安装到真实手机。** 安装脚本必须明确指定已核实的 `emulator-5554`，并先确认模拟器没有真正的支付宝。正式测试 APK 仅构建 `:app:assembleDebug`，不包含此模块。

可用模式：`nodes`、`notify`、`canvas`、`secure`。通过 Intent 的 `amount`、`transaction`、`status` 传入合成内容；支付金额与交易号均为虚构。`secure` 用于验证系统拒绝安全窗口截图时，采集端能如实报告并停止。
