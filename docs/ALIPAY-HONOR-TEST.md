## 开启与检查

打开「记一笔 · 支付宝测试」底部的“自动”，页面标题为“支付宝自动记账”。分别点击“1 · 通知读取”“2 · 付款页面读取”“截图 OCR”，阅读说明后再开启；这三项初始关闭。界面分“未开启 / 待授权 / 待连接 / 已连接”，并提供本次运行事件计数与最近处理原因。下列系统菜单名称不保证在每台 MagicOS 构建上完全相同。

1. **通知读取**：从应用按钮进入系统通知使用权/通知读取设置，给“记一笔 · 支付宝通知读取”授权。普通“允许发送通知”只决定本应用能否发提示，不等于能读支付宝通知。支付宝自身须允许生成相应付款通知；如果它根本没发系统通知，这条路径就没有凭据。Android 通知服务在断开后不会继续收到事件，重新绑定也不能越过用户授权。[Android NotificationListenerService](https://developer.android.com/reference/android/service/notification/NotificationListenerService)
2. **无障碍成功页读取**：从应用按钮进入系统无障碍设置，找到“记一笔 · 支付宝页面读取”，阅读用途后按系统提示授权，再返回核对连接状态。只开启支付宝适配。不要将“服务授权成功”当成已经读到支付宝页面；WebView、自绘区域或安全内容可能没有可读节点。[Android 服务配置](https://developer.android.com/guide/topics/ui/accessibility/views/service)
3. **截图 OCR 单独开关**：本版仅在 Android 14 / API 34 及以上使用指定窗口截图；MagicOS 版本名不能单独代替 Android API 检查。Android 13 及以下仍可读取获准的页面节点，但不提供截图 OCR。系统能显示截图授权说明，不等于本版设备已满足截图条件。先启用“付款页面读取”并确认服务连接，再进入“截图 OCR”点击“同意并开启本地 OCR”。自动截图只在可读文字已有成功状态但缺金额时尝试；完全没有可读文字时不会自动截图。若要主动验证该页，点击“测试当前付款页截图→开始 8 秒倒计时”，由用户在倒计时内切回支付宝付款成功页；只执行一次，可返回应用取消。OCR 结果必须核对后才计入统计。`takeScreenshotOfWindow()` 自 API 34 提供，安全窗口等条件会失败；代码会停止而不绕过，也不降级成整屏截图。[Android 截图能力与错误](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)
4. **荣耀后台运行**：荣耀官方覆盖 MagicOS 10 的支持页给出的路径为：设置中搜索“启动管理/应用启动管理”，找到本应用，关闭该应用自动管理，在弹框中允许后台活动。必要时在最近任务中下滑该应用卡片加锁；不同固件显示以实际为准。后台保护有助于降低清理概率，不能承诺永久存活。[荣耀后台运行说明](https://www.honor.com/cn/support/content/zh-cn00406916/)、[MagicOS 10 应用管理](https://www.honor.com/cn/support/content/zh-cn15886795/)

**若侧载 APK 提示受限制的设置**：MagicOS 10 安全白皮书第 69 页说明，从 9.0 起，非可信来源安装应用的无障碍等关键权限会默认受限，只有用户明确确认可信并解除限制后才可授权。先核对安装包来源与本轮版本；是否选择信任由用户本人在系统界面决定。Android 通用帮助说明可能在“设置→应用→应用信息→更多→允许受限制的设置”操作，但未验证荣耀 100 Pro 当前固件是否采用此路径，不将它写成确定入口。若没有官方系统入口，记录系统提示，停止该通道测试；无需关闭全局安全防护或使用调试命令。[荣耀 MagicOS 10 安全白皮书](https://www.honor.com/content/dam/honor/cn/overview-test/img/MagicOS-10.0%E5%AE%89%E5%85%A8%E6%8A%80%E6%9C%AF%E7%99%BD%E7%9A%AE%E4%B9%A6.pdf)、[Android 受限设置说明](https://support.google.com/android/answer/12623953?hl=en)

## 测试顺序

先验通知单路，再验无障碍单路，最后开启两路与 OCR。每次先记录账本条数和当月已确认支出，再进行一项操作，核对明细、待确认、统计与诊断。自动保存必须以明确付款成功、可靠金额及来源识别为前提；信息不足留待确认或跳过，不用 `0` 金额补出账单。尚未识别到交易时间、商户等信息时，界面中的采集时间/待核对占位不能当成支付平台提供的事实。分类不确定可以归“其他”，不应因缺分类就虚构交易。

以下“通过标准”是要验证的产品要求，**不是已经通过的结果**。同一条用例要记录来源 `通知 / 页面 / OCR`、设备状态、观察结果和耗时；当前所有结果均为待测。

当前解析只自动处理人民币消费；类别先记“其他”。通知缺交易时间时可使用采集时间；页面缺时间、缺商户、OCR、身份歧义等进入待核对。可靠交易号/同一事件用于精确防重，近时间同额等弱关联只能提醒核对，不硬合并；因此“两路都开”可能出现一笔已确认加一条待核对，需用户判断，尚未达到所有场景无操作记账。

OCR 可能丢失货币符号或把金额标签识别为异体字。本版仅针对明确的 OCR 实付金额标签兼容“额/額”；没有金额标签的裸数字仍不会被猜作付款金额。商户等识别文字保留待核对，不自动改写为推测值。

| --- | --- | --- | --- |
| A01 | 仅通知开启；用户完成一笔日常支付宝消费 | 如果支付宝发送含成功状态和金额的通知，可产生正确账目；若未发或字段不足，诊断明确无事件/待确认，不声称已自动记录 | 待测 |
| A02 | 仅无障碍开启，OCR 关闭；支付后停留成功页 | 可读文本足够时保存；不可读或不足时不误记、不截图、不从金额按钮推定付款 | 待测 |

## 反馈与诊断

每条失败记录：APK 版本、MagicOS 完整版本、支付宝版本、用例编号、时间、来源开关、系统授权/服务连接状态、前台/后台/锁屏、结果类型（保存/重复/待确认/未匹配/截图失败）和错误码。应用“自动→查看诊断记录”显示最近 30 条；本地最多保存 100 条状态日志，事件计数只代表当前进程。用“导出诊断文件”通过系统保存面板选择位置，文件默认名为 `ink-ledger-alipay-diagnostics.json`，保存后再决定是否交给开发者。

JSON 包含应用内同意/开关、权限/连接状态、通知/页面/OCR 次数、保存/待确认/重复次数以及日志时间、来源、固定错误码和说明；不含通知原文、页面文本、金额、商户、完整交易号、captureId 或截图。APK 与系统/支付宝版本、场景编号仍须在反馈中另行补充，不要以为导出文件已包含这些环境信息。

本版源码禁用系统自动备份，并在数据提取规则中排除云备份与设备迁移的数据域；尚未验证荣耀换机/恢复行为。诊断导出由用户单独选择文件位置，不是自动上传，也不包含可还原账本的备份。

先提交不含原始账单内容的状态摘要。确需补充识别样本时，只由用户主动提供脱敏后的那一条：保留成功/失败词、金额格式、字段顺序；遮去姓名、完整订单号、账号、银行卡、余额、二维码和无关通知。未经用户选择，不导出整份通知历史、无障碍树或整屏图片，不要求 ADB 日志。

如果没有任何事件，先看系统权限/连接和支付宝是否确实发通知；有事件但未匹配，再核对支持文案；OCR 失败则记录系统错误码与是否安全窗口。不同层次的问题不能统一显示为“识别失败”，也不能以不断尝试截图掩盖权限被拒绝。

## 能力与发布结论

只有完成对应矩阵后，才能描述“在这个 APK、该系统/支付宝版本及这些场景下验证可用”。通知不保证每笔消费都会发出；页面受 UI 版本、WebView 可读性和系统保护影响；OCR 会出错。Android 15 还会对敏感通知内容实施限制，不能承诺读取任意原文。[Android 15 行为变化](https://developer.android.com/about/versions/15/behavior-changes-all#sensitive-notifications)

ML Kit 中文捆绑模型是独立第三方依赖，不是 AutoAccounting 代码。输入/输出在设备处理与 SDK 指标收集是不同事项。本次成功交付构建的打包 Manifest 及最终 APK 包信息均已核实：仅请求应用自身签名级动态接收器权限，没有 `INTERNET`、`ACCESS_NETWORK_STATE`、存储、悬浮窗或发送通知权限。这个权限事实不能写成对系统其他进程和用户导出目标的全系统网络审计结论。[ML Kit 接入](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)、[SDK 隐私条款](https://developers.google.com/ml-kit/terms)、[本版第三方说明](../android/THIRD-PARTY-NOTICES.md)

侧载测试成功不代表荣耀应用市场审核通过。公开版仍须提交最终用途说明、通知与无障碍显著说明/同意、关闭和撤回能力、数据最小化、SDK/许可披露，并按平台实际反馈处理；当前没有已获准上架或系统胶囊准入的证据。[荣耀审核规范](https://developer.honor.com/cn/doc/guides/100879)
