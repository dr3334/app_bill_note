# 支付宝引导图素材说明

三张图片来自用户提供的真实付款成功、转账成功和账单详情截图。用户授权脱敏后用于应用内提示；本项目通过内置 image_gen 编辑成展示副本，已逐张核对遮盖区域、类型标签与关键金额。

| 展示资源 | 保留的识别示例 | 已遮盖内容 |
| --- | --- | --- |
| [付款成功](../android/app/src/main/res/drawable-nodpi/guide_alipay_payment.png) | 实付 8.60、原价 8.80、优惠 0.20、红包广告 0.5 | 状态栏、商户名称 |
| [转账成功](../android/app/src/main/res/drawable-nodpi/guide_alipay_transfer.png) | 转账成功、298.00、付款方式标签及广告干扰 | 状态栏、两处收款人名称、头像、亲情卡关联人 |
| [账单详情](../android/app/src/main/res/drawable-nodpi/guide_alipay_bill.png) | -8.50、交易成功、支付时间字段、商品说明 | 状态栏、商户、完整支付时间、收款方全称 |

灰块是隐私遮盖，不表示该字段在真实页面中缺失。展示副本经图片编辑，不作为逐像素还原或实际 OCR 输入验证；解析测试采用脱敏人工转录，测试日期和时刻为虚构值。

原始截图、私人来源路径、含原始信息的编辑提示词和外部参考图库仅本地保留，不进入 GitHub 源码或 APK。支付宝界面、商标及广告元素仅用于解释识别规则，不表示官方合作；未将 AutoAccounting 公开截图或旧官方截图随应用分发。
