# 0.4：按真实页面核对支付宝识别

安装已单独交付的 0.4 测试包，或按[首页构建说明](../README.md#从源码构建)生成 APK。使用同签名测试包时可直接覆盖 0.3 或原支付宝测试版，不用卸载；换电脑自行构建的调试签名可能不同，不能直接覆盖。源码仓库不包含安装包。

## 三类页面，三个处理结果

| 页面 | 本版处理 | 你要核对什么 |
| --- | --- | --- |
| 支付成功 | 取标题附近主金额；示例实付 8.60 元 | 不取原价 8.80、优惠 0.20、广告红包 0.5。示例没有完整支付时间，先待核对 |
| 转账成功 | 专门识别为转账并跳过自动记账 | 不增加消费，不生成待核对账目；诊断显示转账未入消费。如需记账，在明细手动记一笔，类型选“转账” |
| 账单详情 | -8.50 作为 8.50 元支出，使用账单内支付时间 | 不把“收钱码收款”当收入；不使用状态栏时钟。旧账单先核对，避免已有记录被重复确认 |

金额不明确时不会从广告或优惠数字猜一个金额，也不会创建零元记录。截图 OCR 的付款/账单候选全部先待核对。

## 引导在哪里

第一次进入仍显示可跳过的四步引导，第二步可看付款实图并进入三类页面。以后在 **自动 → 使用指南** 或 **设置 → 使用指南 → 支付宝三类页面 · 真实图解** 重看。

图例可以切换付款、转账、账单，点图片或“查看大图”后上下滚动。灰块遮盖姓名、商户、头像、亲情卡关联人名、状态栏和交易时间等隐私；账单图中支付时间是被遮盖，不是该字段原本缺失。展示副本由原图编辑，关键金额保留。看示例不会授权、识别或生成账目。

升级用户不会被强制重复弹首次引导，从上述入口查看新图解即可。

## 在你手机上试

1. 自动页选择支付宝，完成付款页面读取授权，确认显示“已连接”。
2. 正常付款后在真实支付宝成功页停留片刻，或打开已有的单笔账单详情；回明细检查金额、类型、时间及笔数。不要为了测试额外付款或转账。
3. 没结果时，Android 14+ 可在单独同意 OCR 后点“识别当前付款页”，选择支付宝，开始 8 秒倒计时，再切回支付宝对应页面。只识别一次。
4. 检查“自动 → 查看诊断记录”。转账应有 `TRANSFER_NOT_EXPENSE`，不会新增消费；主金额缺失时应有 `NO_AMOUNT`；OCR 候选应待核对。
5. 同一账单重复打开时检查没有直接新增已确认支出；不同页面若缺少可靠共同交易号，可能需要人工判断是否同笔，不要把两份凭据重复确认。
6. 在使用指南切换三类图、打开大图、返回；可顺便看深色模式、大字号和横屏是否清楚。

本功能读取的是所选支付应用的当前页面，不从相册或本地参考图库导入；查看这三张示例图片本身不会触发记账。
